# ТЗ для AI-агента

Студия умеет собирать самодостаточное ТЗ для AI-агента по планируемым узлам
карты и проверять результат. Разработчик расширяет систему описаниями в
студии, пакет выдаёт документ, агент пишет код, `studio verify` проверяет.

## Команды

```bash
studio brief                      # .studio/agent-brief.md, все готовые задачи
studio brief --stdout             # ТЗ в stdout, без записи
studio brief --only CancelOrder   # одна задача (можно повторять --only)
studio brief --scenario cancel_order --map related
studio brief --include-empty      # узлы без описания тоже становятся задачами
studio verify                     # последнее ТЗ
studio verify .studio/agent-brief.md --json
```

`studio export` остался устаревшим псевдонимом `studio brief --map full`:
команда печатает предупреждение и собирает ТЗ.

## Что попадает в документ

- задача — планируемый узел с непустым описанием;
- критерии приёмки, целевой файл-план, якорь и связи с путями к соседям;
- образец реализации того же вида (домен → каталог → id), до 40 строк;
- карта проекта в режимах `full`, `related`, `compact`, `none`;
- правила работы агента (`studio/agent/rules.md`);
- необязательные правила проекта — `studio.rules.md` в корне проекта;
- диагностики, которым карта не доверяет.

Планируемый узел без описания попадает в раздел «Не готово к реализации».
Флаг `--include-empty` превращает его в задачу «реализуй по имени и связям».

## Проверка

`studio verify` находит узел по якорю и виду, проверяет, что он больше не
планируемый, что ожидаемые рёбра подтверждены кодом (`Edge.origin = code`),
что блоки `description`/`acceptance` не потеряны, что для критериев есть тест
и что в файле нет error-диагностик.

Статусы: `выполнено`, `частично`, `не сделано`. Код возврата: `0` — все
задачи выполнены, `1` — есть незавершённые, `2` — ТЗ не найдено.

## Безопасность

Генерация локальная и офлайн. В документ не попадают значения `.env*`; секреты
в образцах кода маскируются. ТЗ содержит фрагменты кода и описания проекта —
решение об отправке во внешний AI-сервис принимает пользователь.
