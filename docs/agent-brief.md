# ТЗ для AI-агента

Студия собирает локальный markdown-документ из планируемых узлов с описанием
и карты проекта. Документ можно скопировать, скачать или сохранить в проект;
решение об отправке во внешний AI-сервис принимает пользователь.

## Команды

```bash
studio brief                      # .studio/agent-brief.md, весь проект
studio brief --stdout             # ТЗ в stdout, без записи
studio brief --only CancelOrder   # только выбранный узел (можно повторять)
studio brief --scenario cancel_order --map related
studio brief --include-empty      # включить узлы без описания
studio verify                     # проверить последнее ТЗ
studio verify .studio/agent-brief.md --json
```

## Что попадает в ТЗ

- постановка и таблица задач;
- правила работы из `studio/agent/rules.md`;
- правила проекта из `studio.rules.md`, если файл есть;
- задачи: целевой файл, якорь, домен, место в запросе, описание, критерии,
  связи, образец кода того же вида, что можно переиспользовать из nested-узлов,
  проверка через `studio verify`;
- карта проекта: дерево запроса, модели, тесты, неполные узлы;
- «Не готово к реализации» — планируемые узлы без описания;
- предупреждения по коду и жёлтые пометки;
- формат якорей и связей из `.studio/metadata.json`;
- отчёт и проверка.

Описания берутся только из `.studio/metadata.json`. Код проекта студия не
изменяет.

## Проверка: только факты

По каждой задаче `studio verify` задаёт три вопроса:

1. узел появился в коде?
2. ожидаемые связи есть в коде?
3. тест с именем узла есть?

Статусы: **выполнено** (все три «да»), **частично** (узел есть, но связи или
теста нет), **не сделано** (узла нет). Никаких «почти» и процентов.

Коды возврата: `0` — все задачи выполнены, `1` — есть «частично» или «не
сделано», `2` — ТЗ не найдено. Отчёт печатает по каждой задаче цепочку
`узел → связи → тест → итог` с путями `path:line`.

## Ограничения

Документ собирается локально и детерминированно: один граф и одни настройки
дают одинаковые байты, кроме строки «Сформировано». Секреты из `.env*` в
документ не попадают.
