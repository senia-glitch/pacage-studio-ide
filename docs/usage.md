# Как пользоваться студией

## Быстрый цикл

```powershell
studio doctor                  # проверить источники и окружение
studio                         # автоскан + интерфейс, открывает браузер
studio scan [--json]           # только скан → .studio/graph.json
studio list [--json]           # сценарии в терминале
studio brief [--stdout] [--only ANCHOR] [--scenario NAME]
studio verify [BRIEF]          # проверить выполнение ТЗ
studio export [--out PATH]     # устаревший псевдоним brief --map full
studio install-full            # fastbase[full] в текущий venv
```

Про ТЗ для AI-агента — в [agent-brief.md](agent-brief.md).

## Вкладки

### Карта

Эндпоинты fastbase по HTTP-методам и доменам. Поиск (`/`) фильтрует по имени,
URL, домену и описанию. Вложенные узлы эндпоинта видны прямо на карточке;
переключатель **«скрыть вложенные»** убирает их с карты, но не из инспектора.

### Сценарий

Путь одного сценария: `endpoint → scenario → io → model`, тесты и вложенные
узлы рядом с родителем. В инспекторе — описание, критерии, домен, блок
«Почему жёлтый», кнопки «Открыть в VS Code» и «Копировать путь:строка».

Правки описания, критериев и домена сохраняются при потере фокуса в
`.studio/metadata.json`. Код проекта не меняется.

### Создание

Нарисуйте будущие узлы и связи, заполните описание. «Создать» запишет план в
`.studio/metadata.json` и создаст новые файлы-скелеты с одной строкой
`# TODO:`. Существующие файлы не перезаписываются; если не удалось создать
хоть один файл, откатывается всё.

## Метаданные

Описания, критерии, домены, дополнительные связи и планируемые узлы хранятся
только в `.studio/metadata.json`. Формат — в
[metadata-format.md](metadata-format.md).

## Сохранение состояния

Раскладка, зум, выбранная вкладка и узел, черновик «Создания», переключатели
«скрыть метаданные» и «скрыть вложенные» переживают F5: всё лежит в
localStorage браузера. В проект ничего не пишется.

## Диагностика

Бейдж **⚠ N** открывает панель с группировкой по уровню и фильтром по коду и
тексту. Жёлтые пометки помечены как «неточность». «Копировать всё» отдаёт
markdown-список. Коды — в [troubleshooting.md](troubleshooting.md).

## Лог

`.studio/studio.log` — журнал сканов, ошибок и записи. GET-запросы не пишутся;
`studio dev --verbose` добавляет HTTP. Удалить `.studio/` безопасно: граф и
метаданные будут созданы заново (метаданные — только при явном сохранении).
