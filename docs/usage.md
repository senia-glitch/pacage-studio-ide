# Как работать со студией

## Повседневный цикл

```powershell
studio doctor                  # одна команда: что найдено и что не так
studio                         # скан + интерфейс, браузер откроется сам
studio scan [--json]           # только пересобрать .studio/graph.json
studio list [--json]           # сценарии в терминале
studio brief [--stdout] [--only ANCHOR] [--scenario NAME]
studio verify [BRIEF]          # проверить выполнение ТЗ
studio export [--out PATH]     # устаревший псевдоним brief --map full
studio install-full            # fastbase[full] в текущий venv
```

Подробности о ТЗ для AI-агента — в [agent-brief.md](agent-brief.md).

Остановка интерфейса — `Ctrl+C`. При старте пакет сканирует проект и только
потом открывает браузер. Сервер слушает только loopback; запись защищена
одноразовым токеном, страница получает его в `<meta name="studio-token">`.

## Вкладки

### Карта

Эндпоинты fastbase в областях «домен → HTTP-метод». Поле поиска (`/`)
фильтрует по методу, URL, имени функции, домену и описанию; Enter открывает
сценарий первого совпадения. Чипы доменов и `Ctrl+K` помогают найти узел.

### Сценарий

Слева список сценариев (метод → домен, внизу «Неполные»), в центре путь
`endpoint → scenario → io → model` и тесты, справа форма метаданных.

Кнопка **↗** на карточке и **Открыть в редакторе** в форме открывают строку
кода в выбранном редакторе. Редактор выбирается в шапке и запоминается.
`O` открывает выбранный узел, `F` вписывает карту, `+`/`−` меняют зум,
`H` скрывает метаданные, `?` показывает горячие клавиши.

Правки описания, критериев и домена сохраняются при потере фокуса
(`Ctrl+Enter` в поле — тоже сохранить). Индикатор внизу формы показывает
«Сохранено ✓ / Сохранение… / Не сохранено / Ошибка / Конфликт».
Если файл изменился в IDE, студия предложит сохранить ваши правки поверх,
взять версию из кода или отменить. Удалённые устаревшие блоки можно вернуть
кнопкой «Отменить».

Раскладка, зум, выбранные вкладки, узел и черновик «Создания» переживают F5:
они хранятся в localStorage браузера и в проект не пишутся.

### Создание

У каждой области вида узла есть `+`. Заполните имя/якорь, при необходимости
метод и путь, протяните связи от точки справа. «Создать» генерирует только
файлы с метаданными, по одному на узел; существующие файлы не перезаписываются.
Если имя уже занято якорем кода, конструктор откажет и ничего не запишет.

## Метаданные

Правила маркеров, якорей и сохранения — в
[metadata-format.md](metadata-format.md). Каждый раздел обрамляется
`# studio: <раздел> start/end`; блок ставится над якорем кода.

Домен назначается только эндпоинту и наследуется вниз по потоку. «Неполный»
узел — недостижимый из эндпоинтов по направленным связям.

## Диагностика

Бейдж **⚠ N** в шапке открывает список: сообщение, `file:line` (открывается
в редакторе), подсказка и код. Код можно найти в
[troubleshooting.md](troubleshooting.md). Пустая карта всегда объясняет,
какие пути проверены и что поправить.

## Логи

`.studio/studio.log` — сканы, записи, ошибки. GET-запросы не пишутся;
`studio dev --verbose` включает всё. Папка `.studio/` не коммитится.
