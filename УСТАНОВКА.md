# Установка pacage-studio

Studio — визуализатор пути запроса (`HTTP → endpoint → scenario → io → model`)
с режимом планирования и scaffold. Ставится в **ваш venv** проекта.
Существующий код проекта не меняется: служебные файлы — в `.studio/`,
файлы-скелеты создаются только по явной команде («Создать файлы» в UI /
`studio scaffold`) и помечены комментарием в первых строках.

## Полная установка (рекомендуется, с флагом `[full]`)

Тянет студию + весь стек: `fastbase`, `core-package`, `event-infra` из GitHub.

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

Если python называется `py`:

```powershell
py -3 -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

## Минимальная установка (только студия)

Только `pydantic`, без стека fastbase/core/event-infra:

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

## Локальная установка (из клона репозитория)

```bash
git clone https://github.com/senia-glitch/pacage-studio-ide.git
cd pacage-studio-ide
pip install -e ".[full]"    # или pip install -e .
```

## Проверка

```powershell
studio help
```

## Быстрый старт

```powershell
cd <папка_вашего_проекта>
studio scan                  # код → .studio/graph.json
studio dev                   # http://127.0.0.1:8777
studio list                  # сценарии с endpoint'ами и io
studio export                # md-инструкция для AI-агента (или --format json)
```

`studio dev` поднимает интерфейс; граф сканируется сам при первом запросе.
В браузере переключатель **Просмотр / Конструктор**:

- **Просмотр** — карта существующего кода и созданных сценариев; клик по узлу
  открывает инспектор, где можно править **описание** (сохраняется в код
  блоком `# studio: description …`) и **домен** сценария;
- **Конструктор** — мастер создания нового сценария (эндпоинт, сценарий,
  операции БД) и кнопки **Создать файлы** (scaffold файлов-скелетов)
  и **Очистить план** (удалить `.studio/plan.json`).

После «Создать файлы» план сохраняется — очищайте его сами, когда он больше
не нужен.

Другие команды:

```powershell
studio scaffold              # показать, что scaffold создаст из плана (--yes — сразу)
studio reset                 # удалить .studio/plan.json (план)
```

## Обновление

Та же команда, что и установка:

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

После обновления перезапустите `studio dev` и обновите страницу в браузере: **Ctrl+F5**.

## Что создаётся в проекте

| Путь | Что это |
|---|---|
| `.studio/graph.json` | граф сценариев (схема v4) |
| `.studio/plan.json` | патчи плана из режима Конструктор (origin=user/stale) |
| `.studio/studio.log` | лог запуска и запросов |
| `.studio/.gitignore` | `graph.json` + `plan.json` + `studio.log` (чтобы не коммитились) |

По явной команде scaffold дополнительно создаются файлы-скелеты с маркером
`# studio: scaffold ...` в первых строках, закомментированные блоки моделей
в `models.py` и `# TODO`-комментарии в сценариях (в UI — кнопка
«Создать файлы»). Ничего больше пакет
не пишет; существующий код не правится.

## Troubleshooting

| Симптом | Решение |
|---|---|
| `studio` не найдена | Убедитесь, что активирован нужный venv, или вызывайте `python -m studio` |
| Не видно новые фичи в UI | Перезапустите `studio dev`, затем **Ctrl+F5** в браузере |
| Пустые описания узлов | В коде проекта нет docstring — добавьте `"""..."""` к функциям/классам и выполните `studio scan` |
