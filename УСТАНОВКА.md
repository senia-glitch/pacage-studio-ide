# Установка pacage-studio

Studio — read-only визуализатор пути запроса (`HTTP → endpoint → scenario → io → model`).
Ставится в **ваш venv** проекта. Код проекта не меняется.

## Полная установка (рекомендуется, с флагом `[full]`)

Тянет студию + весь стек: `fastbase`, `core-package`, `event-infra` из GitHub.

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

Если python называется `py`:

```powershell
py -3 -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

## Минимальная установка (только студия)

Только `pydantic`, без стека fastbase/core/event-infra:

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

## Локальная установка (из клона репозитория)

```bash
git clone https://github.com/senia-glitch/pacage-studio-ide.git
cd pacage-studio-ide
pip install -e ".[full]"    # или pip install -e .
```

## Проверка

```powershell
studio help
```

## Быстрый старт

```powershell
cd <папка_вашего_проекта>
studio scan                  # код → .studio/graph.json
studio dev                   # http://127.0.0.1:8777
studio list                  # сценарии с endpoint'ами и io
```

`studio dev` поднимает интерфейс; граф сканируется сам при первом запросе.
Сервер только читает: код проекта не меняется, пишется лишь `.studio/`.

## Обновление

Та же команда, что и установка:

```powershell
python -m pip install --upgrade --force-reinstall "pacage-studio[full] @ git+https://github.com/senia-glitch/pacage-studio-ide.git"
```

После обновления перезапустите `studio dev` и обновите страницу в браузере: **Ctrl+F5**.

## Что создаётся в проекте

| Путь | Что это |
|---|---|
| `.studio/graph.json` | граф сценариев |
| `.studio/studio.log` | лог запуска и запросов |
| `.studio/.gitignore` | `graph.json` + `studio.log` (чтобы не коммитились) |

Больше пакет ничего не пишет. Код проекта не трогается.

## Troubleshooting

| Симптом | Решение |
|---|---|
| `studio` не найдена | Убедитесь, что активирован нужный venv, или вызывайте `python -m studio` |
| Не видно новые фичи в UI | Перезапустите `studio dev`, затем **Ctrl+F5** в браузере |
| Пустые описания узлов | В коде проекта нет docstring — добавьте `"""..."""` к функциям/классам и выполните `studio scan` |
